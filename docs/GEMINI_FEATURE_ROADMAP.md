# מפת דרכים לפיצ׳רים בהשראת Gemini

המטרה היא להוסיף יכולות שמייצרות ערך אמיתי למשתמש, תוך שמירה על שרת יחיד, הרשאות ברורות ותיעוד מלא של העלות והמקורות.

## הושלם בסבב הנוכחי

- בחירת משפחת מודל בנפרד מבחירת הגרסה.
- רמות חשיבה אוטומטית, מינימלית, נמוכה, בינונית וגבוהה.
- התאמה אוטומטית בין `thinkingLevel` של Gemini 3 לבין `thinkingBudget` של Gemini 2.5.
- בקשת תקצירי חשיבה והזרמתם בנפרד מהתשובה למשתמש.
- פתיחה ומזעור של תקציר החשיבה באמצעות הכוכב הכחול, גם בזמן הזרמה וגם בהיסטוריה.

## סדר העדיפויות המומלץ

| עדיפות | יכולת | חוויית משתמש מוצעת | הערת מימוש |
|---:|---|---|---|
| 1 | Google Search ו־URL Context | מתג “חיפוש ברשת”, מקורות וקישורים ליד כל טענה | להציג grounding metadata וציטוטים; להבהיר עלות ושליחת URL לספק |
| 2 | Deep Research | מצב מחקר שיוצר תוכנית, מתקדם ברקע ומפיק דוח עם מקורות | עבודה ארוכה בתור הקיים, שמירת checkpoints ואפשרות ביטול |
| 3 | Canvas / Artifacts | מסמך או קוד editable לצד השיחה, עם גרסאות ותצוגה מקדימה | לשמור artifact בנפרד מהודעות; sandbox להרצת קוד ותצוגה |
| 4 | Code Execution וניתוח נתונים | העלאת CSV/Excel, הרצת חישובים והצגת טבלאות וגרפים | סביבת ביצוע מבודדת, מגבלות CPU/זיכרון/זמן וקבצי פלט |
| 5 | File Search / ספריית ידע | אוסף קבצים קבוע שאפשר לצרף לשיחות בלי להעלות מחדש | הרשאות לפי משתמש, אינדוקס, מחיקה ושקיפות אילו מקורות שימשו |
| 6 | יצירה ועריכת מדיה | יצירת/עריכת תמונה, וידאו, TTS ואודיו מתוך סרגל המצבים | להציג מודלים ייעודיים בנפרד ממודלי שיחה ולחשב עלות מראש |
| 7 | Live | שיחת קול רציפה, ובהמשך מצלמה ושיתוף מסך | WebSocket קיים כבסיס; נדרשים הרשאות מדיה, reconnect ומדדי latency |
| 8 | Gems / פרופילים | תבניות אישיות של הוראות, מודל, כלים וקבצי ידע | הרחבה טבעית של מערכת התוספים והגדרות המשתמש |
| 9 | כלי למידה | Audio Overview, שאלונים, flashcards ו־Storybook | לייצר artifacts שמורים ולשמור קישור ברור לחומר המקור |

## עקרונות מוצר

1. מתגי כלים יוצגו בסרגל השליחה; הגדרות נדירות יישארו בחלונית המתקדמת.
2. מודלי שיחה, תמונה, וידאו, אודיו ו־Live יוצגו כקטגוריות נפרדות כדי למנוע בחירה לא תקינה.
3. לכל מצב יוצגו מראש התמיכה של המודל, מגבלות הקלט והעלות המשוערת.
4. מקורות, קריאות כלים ותקצירי חשיבה יוצגו כפריטים נפתחים, אך לא יתערבבו בטקסט התשובה.
5. משימות ארוכות ימשיכו לפעול ברקע דרך תור הריצות ויהיו ניתנות לביטול ולחידוש תצוגה.

## סדר מימוש מוצע

השלב הבא המומלץ הוא חיפוש Google ו־URL Context עם ציטוטים. לאחריו כדאי להוסיף Deep Research על גבי מנגנון התורים הקיים, ואז Canvas ו־Code Execution. השילוב הזה נותן את השיפור הגדול ביותר למחקר ולעבודה עם קבצים לפני שנכנסים ליכולות מדיה ו־Live המורכבות יותר.
